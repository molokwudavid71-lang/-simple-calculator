# -simple-calculator

A simple command-line calculator written in Python that performs addition, subtraction, multiplication, and division.

## How to Run

1. Download or clone this repository.
2. Run the program by using Vs code or any python intepreter


## Example

Enter first number: 12
Enter operator (+, -, *, /): *
Enter second number: 3
Result: 36
